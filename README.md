# WB Parser

Сайт мониторинга карточек Wildberries. Вставьте ссылку или артикул, выберите валюту и получите подтверждённые данные из публичного API (`cards/v4/detail`).

## Деплой на Vercel

1. Загрузите эти файлы в GitHub-репозиторий (корень проекта).
2. В Vercel → Add New → Project импортируйте репозиторий.
3. Framework Preset: **Other**, Build Command: пусто, Output Directory: пусто. Deploy.

## Локальный запуск

Для проверки интерфейса требуется Vercel CLI: `npx vercel dev`.

## Ограничения

- Публичное API WB может отвечать 403/429/502 и не гарантирует данные по каждому региону.
- `dest` по умолчанию `-1257786` (не гарантируется соответствие Казахстану), поэтому цена может не совпасть с ценой в приложении в Казахстане. Регион можно переопределить в API запросе: `/api/product?id=440626784&currency=kzt&dest=...`.
- Срок доставки отсутствует в основном API; отображается как неподтверждённый.
- Остатки могут не передаваться или передаваться в иной модели; null обозначает неизвестное значение.
- Наличие источника нужно проверять на целевом сервере после деплоя.
